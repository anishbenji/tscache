Sizes are `wc -c` in kilobytes (1 KB = 1,000 bytes), measured on 2026-11-11; about four bytes make one token. "Protected path" marks files on the protected-path list in the director's `path-checks.md` (outside the repository, owned by the user); these labels are not exhaustive, and that list decides.

## Reading one decision, and `docs/architecture.md` cheaply

Each decision has its own file under `docs/decisions/`, named by its number and a short slug: `01-…` to `08-…` for the rows of architecture §7 (starter §9), `N1-…` to `N70-…` for §8. Architecture §7 and §8 list every decision on one line, with a summary and a link. Read only the file you need:

```sh
cat docs/decisions/N19-*.md                  # one decision, by its number
cat docs/decisions/07-*.md                   # a §7 row: two digits
grep -l "clearAll" docs/decisions/*.md       # which decisions mention a term
grep -n "^## \|^### " docs/architecture.md   # section headings with line numbers
sed -n '620,696p' docs/architecture.md       # one section by its line range
```

To search `docs/architecture.md` for a term, list matching line numbers only (`grep -n -o "clearAll" docs/architecture.md | cut -d: -f1 | uniq`), then read those lines.
