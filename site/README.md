# tscache documentation site

The user documentation, built with VitePress. From the repository root:

```sh
bun run docs:dev     # TypeDoc, then the VitePress dev server
bun run docs:build   # TypeDoc, then the static site in .vitepress/dist
bun run docs:check   # type-checks snippets/ against the built package (bun run build first)
```

- Pages are the Markdown files here. Code examples live in `snippets/` as TypeScript that
  `docs:check` compiles, and pages include them with `<<< @/snippets/file.ts#region`. Pages may also
  include files from `integrations/`, `examples/` and `reference/`, which their own checks compile.
- `api/` is generated by TypeDoc (`typedoc.json`) from the package's TSDoc and is not committed.
- The build fails on a dead link between pages, a link to a repository file that does not exist
  (`.vitepress/config.ts`), and a missing code include. `bun run ci` runs `docs:check` and `docs:build`.
- TypeDoc runs on TypeScript 6, installed here under an npm alias, since TypeScript 7 has no JS API;
  `docs:check` runs from the root with the repository's TypeScript 7.
